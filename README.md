# Orion

Static site generated by the trading system after every run. Served by GitHub Pages.

- `/` performance in percent and the sealed record of every planned entry: each evening a hash of
  each planned entry is published and signed before the trade; a name is revealed, with its planned
  entry, stop and outcome, when the position has closed.
- `/signals/sealed/` the sealed documents, `/signals/revealed/` the revealed items, `/signals/index.json`
  the list, `/signals/PUBLIC_KEY.txt` the Ed25519 public key.
- `/desk/` the operator's full dashboard, stored encrypted.

Verify a sealed document: sha256 of the canonical JSON of `sealed` must equal `sha256`, and the
signature must verify over that hex string with the public key. Verify a revealed item: sha256 of the
canonical JSON of `{"salt": salt, "item": item}` must equal its `commitment`, which must appear in
that session's sealed document.
